# Support

Looking for help with a Gittensor Vanguard project?

- **Questions & ideas** — open a discussion on the relevant repository, if enabled.
- **Bugs & feature requests** — open an issue using the templates on the relevant repository.
- **Documentation** — start with the repository's `README.md`.
- **Security issues** — do not open a public issue; follow [SECURITY.md](SECURITY.md).

Please search existing issues before opening a new one.

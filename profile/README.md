<h1 align="center">Gittensor Vanguard</h1>

<p align="center"><em>Open-source, self-improving agents for the Gittensor ecosystem.</em></p>

---

Gittensor Vanguard builds autonomous software agents — and the benchmarks that optimize them — in the open. Our focus is turning hard software-engineering problems, like repository maintenance, into measurable optimization problems grounded in real GitHub history.

### Projects

- **[vanguarstew](https://github.com/gittensor-vanguard/vanguarstew)** — a general repository-maintainer agent and a time-travel benchmark that scores it against what real maintainers actually did.

### Get involved

Issues and pull requests are welcome. See each repository's `CONTRIBUTING.md` to get started.
